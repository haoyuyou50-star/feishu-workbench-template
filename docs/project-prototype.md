# 项目管理本地原型

入口：同一工作台中的 /project-preview，仅 localhost、127.0.0.1 和 ::1 可访问。
“我的看板”底部有本地原型入口。正式站点不开放此入口；本轮不部署。

## 数据边界

- 使用 8 个示例项目、5 个阶段、14 项任务，首次载入时固定示例日期。
- 数据保存在浏览器 localStorage 的 liufeng-workbench.project-prototype.v1；不同端口和浏览器互不共享。
- 没有项目 API 请求，不创建或修改飞书表格、课程、投奖或个人待办。
- 关联来源只保留文本和安全 HTTP(S) 链接；尚未实现跨看板关联或飞书同步。
- 存储失败保留编辑草稿；损坏数据不自动重置；不同标签页保存前检查 revision，避免覆盖已知的新版本。

## 可体验

项目平铺视图（桌面四列，不按类型分组）、四状态任务视图（待确认、未开始、进行中、已完成）、搜索与提醒筛选、详情后编辑、项目配色、项目/阶段/任务创建与编辑、阶段排序、任务与项目拖动排序、任务跨状态移动、项目及任务归档与恢复、任务与阶段删除确认。

新建项目/任务按钮位于页头搜索与设置之间，与投奖及课程看板一致。两个视图都有归档入口。已完成任务默认显示为项目名与任务名，点击查看完整详情，恢复其他状态时自动展开。项目类型仍保留为详情字段，排序不修改类型。

归档只改变可见范围，不改变完成状态或进度。归档项目时，其任务在工作看板归档视图中可查；恢复项目不会取消任务各自单独设置的归档。旧的本地任务未设置 archived 字段时仍按未归档处理。

任务完成比例与阶段成果确认分开。任务清零或全部完成都不自动关闭项目；阶段删除不删除任务。颜色属于项目，任务继承颜色。

沿用工作台主题、下拉框、日期选择、详情/编辑弹层及局部 FLIP 动效。详情与子任务导航共用一个弹层。
